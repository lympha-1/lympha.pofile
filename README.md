# Lympha Resto – profile page (React + Vite + TypeScript + Tailwind)

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # type-check + production build

Edit phones, links, address, map, about text and share URL in `src/data/profile.ts` (search for REPLACE).
Replace pictures in `public/images/` (hero.webp, map.webp, about-bg.webp, …) and `public/logo.svg`.
